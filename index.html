01 / Abstract

Assistance before users ask.

Proactive LLM agents can turn idle compute into useful support before users ask. Yet even correct work can misread user context, impose review costs, or undermine trust.

This project explores foundations for designing and evaluating proactive agents through three joint objectives: Task Capability, Temporal Allocation, and Trust.

02 / The 3T objectives

What, when, and how far?

Three objectives for thinking about useful proactive assistance.

TC / WHAT

Task Capability

Anticipate relevant needs and correctly perform useful work.

TA / WHEN

Temporal Allocation

Allocate compute according to resource availability and when results are needed.

TR / HOW FAR

Trust

Sustain users’ confidence and appropriate reliance on the agent.

03 / Evaluation environment

Proactivity Gym

An environment for studying proactive assistance as tasks, resources, deadlines, and user preferences change over time.
